# noteバズりタイトル生成スキル

noteプラットフォームに最適化された、読まれやすく・シェアされやすいタイトルを生成する。

## noteタイトルのバズパターン

noteでバズるタイトルには以下の型がある。それぞれの型を使ってタイトル案を生成すること。

### 型①：数字＋具体的ベネフィット型
```
「〇〇を△△するだけで、□□できた3つの方法」
「年収〇〇万円の私が実践する、△個の□□術」
```
- **ポイント**：具体的な数字で信頼性と明確さを出す
- **数字の使い方**：3・5・7・10が読まれやすい。奇数の方がクリック率が高い傾向

### 型②：共感・悩み解決型
```
「〇〇で悩んでいる人へ。△△したら変わった話」
「正直に言う。〇〇は△△するより□□の方がいい」
```
- **ポイント**：読者の潜在的な悩みを言語化し、共感から入る
- **「正直に言う」「本当のことを話す」**などの告白ワードが効果的

### 型③：意外性・逆説型
```
「〇〇をやめたら△△になった話」
「みんなが信じている〇〇の嘘」
「〇〇している人が、実は△△な理由」
```
- **ポイント**：「え、そうなの？」という驚きがシェアを生む
- 常識の逆をいくことで注目を集める

### 型④：体験談・ストーリー型
```
「〇〇を△年続けた私が、今だから言えること」
「〇〇に失敗した話と、そこから学んだこと」
```
- **ポイント**：「私が」「〜した話」などの一人称体験談はnoteと相性が良い
- 失敗談は特に共感・拡散されやすい

### 型⑤：まとめ・保存型
```
「〇〇のすべて。△△から□□まで徹底まとめ」
「保存版：〇〇を始める前に知っておきたいこと」
```
- **ポイント**：「保存版」「完全版」「まとめ」はブックマーク率が上がる
- 後で見返したくなる構成にする

### 型⑥：ターゲット明示型
```
「〇〇な人だけが知っている△△の話」
「△△歳から始めて遅くない、〇〇のすすめ」
```
- **ポイント**：読者が「自分のことだ」と感じると開封率が上がる
- 属性・職業・年齢・状況で絞り込む

## タイトル生成ルール

### 文字数
- **理想：20〜32文字**（スマホ表示で全文見える範囲）
- 40文字超えると途切れるため避ける

### noteアルゴリズムを意識したキーワード配置
- メインキーワードをタイトルの**前半（冒頭15文字以内）**に入れる
- noteの検索はキーワードマッチが強いため、読者が検索しそうな言葉を入れる

### クリックを促す感情ワード（積極的に活用）
- 驚き：「衝撃」「まさか」「知らなかった」「実は」
- 共感：「あるある」「正直」「本音」「告白」
- 希少性：「誰も教えてくれない」「知る人ぞ知る」
- 緊急性：「今すぐ」「〜している間に」「手遅れになる前に」
- 実績：「〇年で」「〇万円」「〇人に読まれた」

### 避けるべきパターン
- 抽象的すぎるタイトル（例：「人生について考えた」）
- クリックベイトすぎて内容とかけ離れたタイトル（読者の離脱・低評価につながる）
- 長すぎるタイトル（40文字超）

## 出力フォーマット

テーマを受け取ったら、6つの型それぞれから1案ずつ、合計**6案以上**のタイトルを生成する。
