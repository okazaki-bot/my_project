# 訴求設計（marketing-brief の書き方）

構成やコピーがうまくいかないときの原因は、ほぼ100%この段階の詰めが甘い。
ここで書くべきは「ページの設計図」ではなく、**読者の頭の中の地図**である。

---

## 1. ペルソナ（1人に絞る）

「30〜50代のファミリー層」はペルソナではない。それは属性の集合であって、人ではない。
コピーは1人に向けて書いたときにだけ、多数に刺さる。

書く項目：

- 名前（仮）・年齢・職業・世帯年収・家族構成
- **いまの状況**：どこに住んでいて、何がきっかけで動き出したか
- **その人の1日**：どの時間に、どんなデバイスで、どんな気分でこのページを見るか
- **すでに取った行動**：何を検索したか、どこに問い合わせたか、誰に相談したか
- **口にしている悩み** と **口にしない悩み**（後者が本命）

例（工務店の建替え案件）：
> 田中さん・42歳・地元メーカー勤務・世帯年収650万・妻＋小学生2人。
> 築38年の実家（親と同居）が寒く、去年の冬に親が体調を崩した。建替えを考え始めたが、
> 住宅ローンを52歳から35年で組めるのか分からず、銀行に行くのが怖い。
> 夜22時、寝室でスマホで「実家 建替え ローン 年齢」と検索している。
> 口にしている悩み：「予算が読めない」
> 口にしない悩み：「自分の年齢で家を建てるのは無理なのでは、と人に言われたくない」

**口にしない悩みを1文で書けたら、この案件は勝てる。**

## 2. 認知段階の判定（最重要）

読者がどこまで分かっているかで、ファーストビューの第一声が変わる。ここを間違えると全部外れる。

| 段階 | 読者の状態 | ファーストビューで言うべきこと |
|---|---|---|
| ① 無自覚 | 問題があることに気づいていない | 問題の存在を可視化する事実・数字から入る |
| ② 問題自覚 | 困ってはいるが解決策を知らない | 「その困りごとには解決の道がある」と示す |
| ③ 解決策自覚 | 解決策の種類は知っている。どれがいいか分からない | 解決策の中でなぜこのやり方か、を示す |
| ④ 商品自覚 | あなたの会社を知っている。他社と比較中 | 他社ではなくなぜ自社か（差別化）を示す |
| ⑤ 確信済み | 買う気がある。あとはきっかけ | オファー・条件・締切をいちばん上に出す |

**流入経路との整合を必ず取る**（ここが実務で最も事故る）。

- 検索キーワードが具体的（「姫路 中古住宅 リノベーション 費用」）＝③〜④。悩みの共感から始めると冗長で離脱する
- SNS広告・チラシQR＝①〜②。いきなり商品説明をすると「で、何?」で終わる
- 指名検索・紹介＝④〜⑤。信頼の再確認と、行動のしやすさだけ整えればいい
- 経路が複数ある場合は、**最も本数が多い経路に合わせる**。全段階に効かせようとしたページは誰にも効かない

## 3. インサイト（読者の本音）

「本音」は、本人が言語化していないから本音である。次の3つの問いで掘る。

1. **なぜ今まで動かなかったのか？** — 動かない理由の中に本音がある
2. **誰に何と思われたくないのか？** — 体裁・見栄・恥。BtoCの高額商材はここが動機の中核
3. **決めた後、誰に説明する必要があるのか？** — 配偶者・親。ページは「その説明の材料」も供給しなければならない

3番目は特に見落とされる。住宅・不動産のような世帯決定商材では、**閲覧者と決裁者が違う**。
「奥さんに見せられるページか」は設計要件である。

## 4. 反論リスト（最低8個）

見込み客が心の中で言う「でも…」を全部書き出す。これが構成の材料そのものになる。

書き方：反論 → それに対して**証拠で**答える手段 → 素材が手元にあるか

| # | 心の声（でも…） | 答える手段 | 素材 |
|---|---|---|---|
| 1 | でも、うちの予算じゃ無理でしょ | 価格帯別の実例3件＋総額の内訳公開 | 【要確認：施工事例の総額】 |
| 2 | でも、この会社ちゃんとしてるの？ | 所在地・スタッフ顔写真・創業年・加盟団体 | ロゴ○ / スタッフ写真× |
| 3 | でも、しつこく営業されそう | 「初回相談で契約を求めません」と明記＋相談の流れを明示 | あり（文章のみで可） |
| 4 | でも、まだ何も決まってないのに相談していいの？ | 「情報収集段階の方が◯割」と数字で許可を出す | 【要確認：相談者の内訳】 |
| … | | | |

**よく効く反論カテゴリ**（漏れがないか照合する）：
価格／信頼性／営業されるのが嫌／自分の条件だと当てはまらない／面倒・時間がない／
今じゃなくていい／失敗したら取り返せない／家族が反対しそう／他社の方が良いかも

答えのない反論が残ったら、それは**サービス側の課題**なので、コピーで誤魔化さずユーザーに報告する。

## 5. ベネフィット翻訳表（3階層）

機能をそのまま書くと誰も動かない。**意味**まで翻訳する。

| 機能（事実） | 効果（何が起きる） | 意味（その人の人生でどう変わる） |
|---|---|---|
| 全棟気密測定 C値0.5以下 | 冬の室温が朝でも下がりにくい | 朝、子どもが布団から出るのを嫌がらなくなる |
| 自社大工が施工 | 引渡し後も同じ人が対応する | 10年後の不具合で「担当者が退職して分からない」が起きない |
| 提携金融機関12行 | 条件の悪い1行で判断しない | 「銀行に断られたら終わり」という不安が消える |

コピーに書くのは主に **意味**、根拠として添えるのが **機能**。
効果だけで止まっているコピーは、正しいが動かない。

## 6. ポジショニング（空いている席を探す）

競合2〜3社のサイトを実際に見て、次を並べる。

| | 競合A | 競合B | 競合C | 自社 |
|---|---|---|---|---|
| 一言で何を主張しているか | | | | |
| 価格の見せ方 | | | | |
| 誰向けだと言っているか | | | | |
| 証拠として使っているもの | | | | |
| 弱点（顧客が不満を持ちそうな点） | | | | |

そのうえで判断する：

- **全社が同じことを言っている軸**は、そこで戦っても差がつかない（例：地域の工務店はほぼ全社が「自然素材」「アフターも安心」と言う）
- **誰も座っていない席**を探す。「◯◯に特化」「◯◯な人はお断り」「◯◯だけはやらない」という**引き算の宣言**は席が空いていることが多い
- 自社の弱点は隠すより**先に開示して条件化**した方が信頼を生む（例：「デザイン住宅は扱いません。断熱性能に投資してください」）

**No.1・地域一番などの優位表現は、根拠が確認できない限り使わない。** 代わりに検証可能な事実（創業年数・施工棟数・対応エリア）で語る。

## 7. 一言訴求（Value Proposition）

次の型で1文にする。型は文章の形ではなく、**要素の抜けを検査するため**に使う。

> 〔誰が〕〔どんな状況で〕〔どうなれる〕。なぜなら〔独自の理由〕だから。

例：
> 52歳・実家の建替えを考える人が、銀行に行く前に予算の上限を知れる。
> なぜなら提携12行の審査基準を前提に、年齢別の借入可能額から逆算して設計するから。

検査項目（1つでも欠けたら書き直す）：
- [ ] 誰向けか読んだ人が自分だと分かるか
- [ ] 得られる状態が具体的か（「安心」ではなく「予算の上限を知れる」）
- [ ] 競合が同じ文を言えないか（言えるならポジショニングが未完成）
- [ ] 嘘・過剰約束が入っていないか

## 8. オファー設計

CVは「読者が支払うコスト」と「得られるもの」の交換である。天秤を見る。

**コストを下げる**
- 入力項目を減らす（氏名・連絡先・要望の3項目で足りることが多い）
- 所要時間を明示する（「入力1分」「電話は3分で終わります」）
- 段階を作る（いきなり来場予約ではなく「資料請求」「オンラインで30分」を用意）

**リスクリバーサル**（不安を先に消す）
- 「相談当日に契約を求めることはありません」
- 「営業のご連絡は1回のみ。不要とお伝えいただければ以降しません」
- 「他社と比較中の方も歓迎です」
- キャンセル・返金・保証条件の明記

**得られるものを具体化する**
「無料相談」ではなく「無料相談で分かること」を箇条書きにする。
> ・ご希望の条件で、いま組める住宅ローンの上限額
> ・その予算で建てられる家の広さと仕様の目安
> ・親御さんの土地を使う場合の名義と税金の注意点

**緊急性**は、実在する理由がある場合だけ使う（開催日・棟数・補助金の申請期限）。
理由のない「今だけ」は信頼を削るので使わない。

## この段階の完了判定

- [ ] ペルソナが1人に絞れていて、「口にしない悩み」が書けている
- [ ] 認知段階と流入経路の整合が取れている
- [ ] 反論が8個以上あり、それぞれに答える手段が決まっている
- [ ] ベネフィットが「意味」の階層まで翻訳されている
- [ ] 競合が同じ文を言えない一言訴求ができている
- [ ] 素材が足りない箇所が全部 `【要確認：…】` になっている
