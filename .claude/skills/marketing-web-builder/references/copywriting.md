# コピーライティング

`03-copy.md` には **実際にページに載る文字をすべて** 書く。「ここに強みを3つ」のようなプレースホルダで済ませない。
ボタン文言、フォームのラベル、エラーメッセージ、電話番号の横の一言まで書く。

---

## 1. キャッチコピー（ファーストビュー）

### 公式ではなく検査項目で作る

キャッチは型に当てはめて作るとすぐ「よく見るコピー」になる。訴求から書き、次の項目で検査する。

- [ ] **誰向けか分かる**（対象が読んで自分だと分かる語が入っている）
- [ ] **得られる状態が具体的**（「安心」「快適」で止まっていない）
- [ ] **競合が同じ文を言えない**（言えるなら差別化が入っていない）
- [ ] **数字がある**（あれば強い。ないなら具体的な状況描写で代替）
- [ ] **30字前後**（スマホで2行以内。40字を超えたら読まれない）
- [ ] **嘘・過剰約束がない**（「絶対」「必ず」「完全」「日本一」は使わない）
- [ ] **主語が「あなた」側**（自社の自慢になっていない）

### ダメな例 → 直した例

| ❌ | 何が問題か | ⭕ |
|---|---|---|
| 高品質な住まいを、安心の価格で。 | 全社が言える。情報量ゼロ | 断熱等級6を標準に。冬の朝も、廊下が寒くない家。 |
| 地域No.1の実績！ | 根拠がない。優位表現は使わない | 姫路市で312棟。地元の工務店として23年。 |
| お客様の理想を叶えます | 誰向けか不明。得られる状態が抽象 | 「親の土地に建てる」を、名義と税金からご案内します。 |
| 中古住宅リノベーション専門店 | 業種名だけ。ベネフィットがない | 築30年を、新築より500万円安く、新築より暖かく。 |
| 創業50年の信頼と実績 | 自社の話。読者の得がない | 50年で建てた家を、いまも同じ大工が点検しています。 |

### サブコピーの役割

キャッチで削った条件・根拠・限定をここで補う。1〜2行。

> 【キャッチ】築30年を、新築より500万円安く、新築より暖かく。
> 【サブ】姫路市・たつの市の中古住宅を、断熱改修込みの総額でご提案します。物件探しから工事まで自社で完結。

## 2. 見出し（各セクションの h2 / h3）

### 見出しだけ通読テスト（必須）

コピーを書き終えたら、**h2だけを上から順に読む**。それだけで話が通じ、
「で、どうすればいいか」まで分かるなら合格。通じないなら見出しがラベルになっている。

| ❌ ラベル型見出し | ⭕ メッセージ型見出し |
|---|---|
| 当社の特徴 | 物件探しと工事を1社でやるから、予算オーバーが起きません |
| 施工事例 | 総額1,850万円・築32年・4人家族の実例 |
| お客様の声 | 「予算を先に決めてくれたので、迷わずに済みました」 |
| よくある質問 | （FAQはラベルでよい。ここだけは例外） |
| 会社概要 | 姫路で23年、312棟。今も同じ大工が点検に伺います |

見出しは**体言止めを避け、文にする**。「充実のアフターサポート」より「引渡し後10年、年1回の点検に伺います」。

## 3. 抽象語の禁止リスト（最重要）

以下の語は、**単体で使ってはいけない**。使うなら必ず直後に具体を添える。
これらが多いページは、内容がないページである。

| 禁止語 | 言い換えの方向 | 例 |
|---|---|---|
| 安心・安全 | 何が起きないのか | 「引渡し後の担当者変更がありません」 |
| 高品質 | どの基準で | 「断熱等級6・耐震等級3を標準仕様に」 |
| 豊富な実績 | 数字で | 「姫路市内312棟」 |
| 丁寧な対応 | 何をするのか | 「初回相談は90分。当日の契約はお願いしません」 |
| お客様第一 | 何を優先するのか | 「予算が合わなければ、他社をご紹介します」 |
| 最適なプラン | 何を基準に | 「年齢別の借入可能額から逆算します」 |
| こだわり | 何をしているのか | 「1棟ごとに気密測定し、数値を報告書でお渡しします」 |
| 快適 | どんな体感か | 「冬の朝、廊下との温度差が3℃以内」 |
| ワンストップ | 何と何が繋がるのか | 「物件探しと工事の見積を、同じ担当が同時に出します」 |
| 実績豊富なスタッフ | 誰が・何年 | 「宅建士2名・二級建築士1名。平均在籍11年」 |

**判定法**：その文を競合が丸ごとコピペして自社サイトに載せられるなら、書き直す。

## 4. 数字の使い方

- **丸めすぎない。** 「約300棟」より「312棟」。端数が信頼を生む
- **比較の基準を示す。** 「500万円安く」だけでは意味がない。「同条件の新築と比べて」を添える
- **時点を書く。** 「2026年7月現在」。特に価格・金利・制度に触れるとき
- **概算は概算と書く。** 「※あくまで概算です。条件により変動します」
- **割合と実数を併記する。** 「7割（212名中149名）」
- 数字を作らない。手元にないなら `【要確認：施工棟数】` にする

## 5. お客様の声の書き方

- **属性を具体的に書く**（40代・4人家族・姫路市・築32年を購入）。属性が近いほど読者は自分に重ねる
- **「決め手」を必ず1つ含める**（なぜ他社ではなくここにしたか）
- **不安だった点 → どう解消したか** の構造にする。褒め言葉だけの声は読み飛ばされる
- 話し言葉のまま。整えすぎると作り物に見える
- 顔写真・手書きアンケートのスキャン画像があれば圧倒的に強い（推奨素材リストに必ず入れる）
- **声は創作しない。** 未提供なら `【要確認：お客様の声（できれば3件・属性つき）】` とし、レイアウトだけ用意する

## 6. CTA・ボタン文言

- ボタンには**行動の結果**を書く。「送信」「お問い合わせ」ではなく「無料で予算の目安をもらう」「見学会の空き枠を確認する」
- 1人称で書くと押されやすい（「資料をもらう」＞「資料請求」）
- ボタンの上に **ハードルの低さ**、下に **次に起きること** を置く

```
まだ検討段階の方が7割です。当日の契約はお願いしません。
┌────────────────────────────┐
│  無料で予算の目安をもらう（入力1分） │
└────────────────────────────┘
送信後、担当の◯◯より1営業日以内にご連絡します。
```

### マイクロコピー（効くのに忘れられる）

- 電話番号の横：「受付 9:00〜18:00／日曜も対応します」
- フォームの上：「※ご入力いただいた内容を営業目的で第三者に渡すことはありません」
- 任意項目：「（任意）分かる範囲でどうぞ。空欄でも大丈夫です」
- 送信ボタン下：「入力内容は送信前に確認画面で見直せます」
- エラー：「電話番号をご確認ください（ハイフンなしでも大丈夫です）」

## 7. トーン別の書き分け

STEP 1で決めたトーンで通す。**1ページ内でトーンを混ぜない。**
以下は同じ内容（中古＋リノベの相談CTA前）を3トーンで書いた例。

### A. 誠実・信頼重視（住宅・不動産・士業などの高額／長期検討商材）

> ### 予算の上限を、物件を探す前に決めておきませんか
>
> 中古住宅の購入とリノベーションで最も多い失敗は、物件を先に決めてしまうことです。
> 工事費が後から積み上がり、当初の予算を300万円以上超えるケースを、私たちは何度も見てきました。
>
> ご相談では、ご年齢とご年収から借入可能額を確認し、工事費を含めた総額の上限を先に出します。
> ご希望に合う物件が見つからない可能性もありますが、その場合も正直にお伝えします。
>
> 初回のご相談で、契約をお願いすることはありません。

特徴：断定を避け、限界も開示する。数字と経験を根拠に置く。煽らない。「〜しませんか」「〜とお伝えします」。

### B. レスポンス広告系（期限のあるイベント・セミナー・キャンペーン）

> ### 8月17日（日）、姫路会場。残り6席
>
> 「中古を買ってリノベ」で予算を300万円オーバーさせる人には、共通点があります。
> ——物件を先に決めていることです。
>
> 90分で、あなたが今組めるローンの上限額と、その予算で買える物件の条件をお持ち帰りいただきます。
> 参加費無料。前回は満席で、7名の方をお断りしました。
>
> ▼ 空き枠を確認する（30秒）

特徴：具体的な期限・残数（**実在するものだけ**）。短文・体言止め・ダッシュを使う。二人称で詰める。
※「限定」「残り◯席」は実際にその通りである場合のみ。虚偽の限定は使わない。

### C. 中間（親しみ＋誠実／地域密着BtoC全般）

> ### 「いくらまで出せるのか」から一緒に考えます
>
> 中古を買ってリノベーション、と考えたとき、いちばん困るのが「結局いくらかかるの？」ですよね。
> 物件が1,200万円でも、工事に700万円かかれば総額1,900万円。ここを先に見ておかないと、あとで慌てます。
>
> ご相談では、まず総額の上限を一緒に出します。そのうえで、その予算に合う物件をお探しします。
> 「まだ何も決まってない」という段階の方が、実はいちばん多いです。
>
> ▼ まずは話を聞いてみる（入力1分）

特徴：「〜ですよね」で共感を1回だけ入れる。具体的な金額で理解を助ける。距離は近いが根拠は示す。

## 8. 日本語の文章ルール（全トーン共通）

- **一文40字前後。** 60字を超えたら切る。スマホでは3行以上の文は読まれない
- **段落は3行まで。** それ以上は空行で割る
- **漢字を開く。** 「頂く→いただく」「下さい→ください」「出来る→できる」「有る→ある」「更に→さらに」「様々→さまざま」
- **同じ語尾を3回続けない。** 「〜ます。〜ます。〜ます。」は単調で読み飛ばされる
- **二重否定・受け身を避ける。** 「〜されないことはありません」→「必ず〜します」
- **「が」で繋げすぎない。** 逆接は1文に1回
- **専門用語は初出で言い換える。** 「C値（家の隙間の量を示す数値。小さいほど良い）」
- **カタカナを減らす。** 「ソリューション」「コミットメント」は地域BtoCでは使わない
- **主語を「弊社」から「あなた」へ寄せる。** 「弊社は◯◯を提供します」→「◯◯が手に入ります」
- **記号の統一**：波ダッシュは「〜」、中黒は「・」、感嘆符はトーンBでも1セクション1回まで

## 9. 使わない表現

根拠が確認できない優位表現・断定は、このスキルでは使わない（表現の適法性判断はスキルの範囲外なので、
そもそも危ない語を避ける方針を取る）。

- 最上級・No.1系：「日本一」「地域No.1」「業界最安」「唯一」
- 断定・保証系：「絶対」「必ず儲かる」「100%」「失敗しません」「完全」
- 不安を過剰に煽る表現：「知らないと大損します」「騙されています」
- 他社の否定：「他社は◯◯しません」（比較は自社の事実の提示にとどめる）
- 医療・健康効果の断定：「アレルギーが治る」「病気になりません」

代わりに使うもの：検証可能な事実（創業年・棟数・対応エリア・保有資格・仕様の数値）、
第三者の言葉（お客様の声）、条件付きの記述（「◯◯の場合、△△となります」）。
