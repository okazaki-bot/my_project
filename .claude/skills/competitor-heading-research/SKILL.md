# 競合記事見出し構成リサーチスキル

指定されたキーワードで検索上位に表示される記事の見出し構成を調査し、自分の記事に活かすべき構成パターンを分析する。

## 調査手順

### Step1：検索上位記事の特定

WebSearchツールを使って、対象キーワードで検索する。

```
検索クエリ例：
- 「[キーワード] site:note.com」（note記事のみ）
- 「[キーワード]」（Google検索上位全体）
- 「[キーワード] 2024 OR 2025」（新しい記事を優先）
```

上位5〜10件のURLを取得する。

### Step2：各記事の見出し構造を取得

WebFetchツールで各記事にアクセスし、以下を抽出する：

- H1（記事タイトル）
- H2（大見出し）
- H3（中見出し）
- H4（小見出し）があれば取得

### Step3：見出し構成の整理

各記事の見出し構成を以下の形式で整理する：

```
📰 記事①
タイトル：〇〇〇〇
URL：https://...
文字数目安：約X文字（ページ量から推定）

構成：
H1: [タイトル]
  H2: [大見出し1]
    H3: [中見出し1-1]
    H3: [中見出し1-2]
  H2: [大見出し2]
    H3: [中見出し2-1]
  H2: [大見出し3]
  ...
```

### Step4：共通パターンの分析

複数記事の見出しを比較して以下を分析する：

**① 必ず登場する見出しトピック（必須カバー項目）**
- 上位5件中3件以上に登場するH2トピックは「読者が期待するコンテンツ」
- 自分の記事でも必ずカバーすべき

**② 差別化できる見出しトピック（独自性のある項目）**
- 1〜2件のみに登場するユニークな見出し
- 競合が薄い領域 = 差別化のチャンス

**③ 見出しの順番パターン**
- 多くの記事が共通して持つ構成順序（例：「定義 → 理由 → 方法 → まとめ」）
- 読者が期待する情報の流れを把握する

**④ 見出しのキーワード使用状況**
- 各H2に含まれるキーワードをリスト化
- 自分の記事の見出しにも活用できるキーワードを抽出

## 注意事項

- WebFetchで取得できない記事（有料記事・ログイン必須）はスキップし、その旨を記載する
- 取得できた記事数が3件未満の場合は、「調査が不十分な可能性がある」と明示する
- 競合調査はあくまで参考情報であり、**コピーは禁止**。独自の視点・情報を加えることを必ずユーザーに伝える
