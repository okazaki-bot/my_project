# 岡崎充輝 お客様向けニュースレター執筆スキル

## このレターの前提

- **書き手**: 日本有数の住宅専門ファイナンシャルプランナー（保険にも精通）
- **読者**: これから家を建てようとしている工務店の見込み客・OB客（住宅ローン契約前後の一般生活者）
- **媒体**: 工務店が自社名で配布する月刊ニュースレターの1コーナー
- **分量**: A4・2枚程度（本文おおむね1,600〜2,400字）。図表・シミュレーション表を1〜2点想定した構成にする
- **納品形式**: 通常はWord（.docx）またはテキスト原稿。図表は「図1：〜」「表1：〜」のキャプションを本文中に置く

## レターの「型」（5要素・必須）

1. **逆張り・常識への疑義から入る**
   世間の常識やニュースの表面的な解釈（「頭金は2割」「フラット35は高い」「金利が上がったから買い時ではない」等）を冒頭で提示し、それを疑う。読者の声・相談の引用（「〜ですよね？」というご相談が増えました）から入るパターンも多い。

2. **必ず具体的な数字とシミュレーションで検証する**
   借入額・金利・返済期間を固定した概算試算（例: 3,500万円・35年・元利均等）を提示し、差額を「約○○万円」と明示する。複数シナリオ比較（ケース①②、金利据え置き vs 上昇）を好む。数値には必ず時点（「2026年5月時点」等）と「あくまで概算・一つの仮説」という留保を付す。

3. **制度・公的発表・金融の仕組みの「裏読み」をする**
   税制改正、国交省リーフレット、フラット35の金利設定、銀行の審査実務などから「国・銀行が本当に発しているメッセージ」を読み解く。インプライド・フォワードレートのような専門概念も、一般読者向けに翻訳して使う。

4. **住宅ローン×資産運用（NISA）のクロス戦略に着地することが多い**
   「守り（固定金利・無理のない借入）と攻め（差額のNISA運用）の両輪」が繰り返し登場する持論。ただし毎回必ず入れる必要はなく、テーマに自然に接続する場合のみ。運用に触れたら必ず「運用にはリスクがある」旨の留保で締める。

5. **締めは「ここまで考えてくれる会社・専門家が信用できる」または「一緒に考えましょう」**
   工務店が配布する媒体なので、最後は読者の行動（相談・ライフプラン作成）と、綿密な資金計画に付き合ってくれるパートナー選びの価値に接続する。

## 文体ルール

- 語り口は「です・ます」基調。ただし断定的な体言止め・「〜である」を要所に混ぜてリズムを作る（例:「そのほとんどが『今後金利は上昇する』と予測しているのにも関わらずです。」「これこそ賃貸の本当の怖さです。」）
- 読者への呼びかけ・共感の「〜ですよね」「〜というものです」「〜かもしれません」を適度に使う
- 決め台詞的な反復フレーズがある: **「『金利の安い変動金利で借りておいて、金利が上昇したら固定金利に借換すればいい』なんていう甘い考えが一番危険」** は複数号で再利用されている持論。金利テーマでは使ってよい
- 見出しは「◯」「①②③」「ケース①」などシンプルな記号。過剰な装飾はしない
- 煽らない。「確実に儲かる」とは絶対に書かず、「理論的には」「計算上は」「あくまで試算」と必ず留保する
- 変動金利を全否定しない。「問題はローンの選び方ではなく、ローンとの付き合い方」というスタンスを守る
- 一人称は控えめ。「FPとしてお伝えしたいのは」「私は〜をお勧めします」を要所でのみ使う

## 執筆・提案フロー

1. **references/past-letters-2026.md を必ず読む**（既出テーマの重複回避＋文体の直近サンプル確認）
2. トピック提案時は、既出テーマと明確に差別化した切り口で、各案に「逆張りタイトル＋想定する数字検証の中身」をセットで示す
3. 発行月の季節性・ニュースフックを考慮する（例: 4月・10月＝銀行の基準金利改定、10月〜11月＝生命保険料控除証明書の到着、12月〜2月＝年末調整・確定申告、年末＝税制改正大綱）
4. 金利水準・制度（住宅ローン控除、フラット35、贈与特例、保険料率等）は執筆時点の最新情報をweb検索で確認してから書く。古い数値をそのまま使わない
5. 原稿はこの型と文体ルールに沿って書き、図表の挿入位置をキャプションで明示する
