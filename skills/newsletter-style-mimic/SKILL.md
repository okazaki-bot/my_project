# ニュースレター文体模倣スキル

ライフプランアドバイザー協会のニュースレター（Wordファイル）の文体・トーン・言い回しを参照し、同じスタイルで記事本文を執筆・書き直しする。

## 参照するWordファイルのパス

以下のディレクトリ内の `校正後データ` フォルダにある `.docx` ファイルを優先的に参照する（校正後が最終版のため）。

```
/Users/okazakimitsuruakira/Library/CloudStorage/GoogleDrive-okazaki@helplife.jp/共有ドライブ/ライフプランアドバイザー協会/ニュースレター関連/ニュースレター/2026/
```

**参照優先順位（新しい月を優先）：**
1. `2026_06/ワード原稿/校正後データ/`
2. `2026_05/ワード原稿/校正後データ/`
3. `2026_04/ワード原稿/校正後データ/`
4. `2026_03/ワード原稿/校正後データ/`
5. `2026_02/ワード原稿/校正後データ/`
6. `2026_01/ワード原稿/校正後データ/`

参照するファイルは `お客様向けニュースレター.docx` を優先し、なければ `巻頭.docx` を使う。ファイルの読み込みには `textutil -convert txt -stdout "[ファイルパス]"` コマンドをBashで実行する。

## 分析済み文体の特徴

以下は実際のニュースレターから抽出した文体の特徴。Wordファイルを読み込んだ場合は、これに追加・更新して使用すること。

### トーン・スタンス
- **親しみやすい専門家**：金融・ライフプランの専門知識を持ちながら、お客様に寄り添う語り口
- **一人称は「私」**：書き手が顔を出し、体験・意見を率直に述べる
- **読者への語りかけ**：「〜ですよね」「〜ではないでしょうか」「〜してみてください」

### 文章構造の特徴
- **導入は読者の悩み・疑問から始まる**：「こんな不安をよく耳にします」「〜と思っている人が意外と多い」
- **問いかけ → 解説 → 結論**の流れ
- **具体的な数字を多用**：「5,000万円」「月々5万円」「35年後」など
- **短文と長文のリズム**：短い断言文のあとに、長い説明文が続くパターン

### 文末表現のパターン
```
断言型：「〇〇なのです。」「〇〇ということです。」
驚き型：「なんと〇〇になっています。」「そうなると〇〇円も〇〇することになります。」
共感型：「〜ですよね。」「〜ではないでしょうか。」
警告型：「〜ということが一番危険です。」「〜することはできないからです。」
推奨型：「〜をお勧めします。」「〜ことが重要ですね。」
```

### 特徴的な言い回し
- 「〜ということを知らない人が意外と多い」
- 「〜なのにも関わらずです」（強調の倒置）
- 「書いてしまえば簡単ですが」（難しさへの共感）
- 「あくまでも〜でしかありません」（誠実な留保表現）
- 「実は〜」（意外性の提示）
- 「正直言って〜」（本音の吐露）
- 「では、〇〇とは何か？」（自問自答形式）
- 「そこで今回は〜」（テーマ提示の接続詞）
- 「〜というのは〜ということ」（定義の言い換え）

### 構成テンプレート
```
1. 読者の悩み・状況の提示（共感）
2. 「実は〜」「ここで〜」で問題の核心を提示
3. 具体的な数字・事例で説明
4. 「では、どうすれば？」と問いかけて解決策へ
5. 結論・推奨アクションを明示
6. 「〜することが重要ですね」で締める
```

## 実行手順

### Step1：最新のWordファイルを読み込む

Bashで以下を実行し、最新月の `お客様向けニュースレター.docx` を取得する：

```bash
textutil -convert txt -stdout "[ファイルパス]"
```

校正後データが存在する最新月から順に試み、テキストが取得できたら分析に進む。

### Step2：文体特徴の最新情報を抽出

読み込んだテキストから以下を抽出・確認する：
- 冒頭の導入パターン（何で始まるか）
- よく使われる接続詞・文末表現
- 数字・具体例の使い方
- 特徴的な言い回し

### Step3：指定された内容を同じ文体で執筆・書き直す

ユーザーから渡された内容（テーマ or 元の文章）を、抽出した文体で書き直す。

**書き直しの際のチェックリスト：**
- [ ] 導入は読者の悩みや状況から入っているか
- [ ] 「実は」「そこで」「では」などの特徴的な接続詞を使っているか
- [ ] 具体的な数字・金額・期間が入っているか
- [ ] 短文と長文が混在したリズムになっているか
- [ ] 「〜ですよね」「〜なのです」などの文末表現が使われているか
- [ ] 最後に推奨アクションか前向きな締めの一文があるか
