# 文字数カウント スキル

ユーザーから渡されたテキストの文字数を、以下の **4パターン** で必ず出力する。

## カウント対象の定義

### 改行
- `\n`（LF）
- `\r\n`（CRLF）
- `\r`（CR）

### スペース（空白文字）
- 半角スペース（U+0020）
- 全角スペース（U+3000）
- タブ文字（`\t`、U+0009）

## 出力フォーマット

以下の表形式で必ず出力すること：

```
📊 文字数カウント結果

| パターン               | 文字数 |
|----------------------|--------|
| 改行あり・スペースあり  |      X |
| 改行あり・スペースなし  |      X |
| 改行なし・スペースあり  |      X |
| 改行なし・スペースなし  |      X |

※ スペース = 半角スペース・全角スペース・タブ文字
```

表の後に、除外した文字数の内訳も補足する：

```
📝 内訳
- 改行文字数：X 文字
- スペース文字数（半角/全角/タブ）：X 文字
```

## カウント手順

1. 元のテキストをそのまま文字列として受け取る
2. 全文字数（改行あり・スペースあり）= `len(text)` 相当
3. 改行を除いた文字数 = 改行文字（\n, \r\n, \r）をすべて除去してカウント
4. スペースを除いた文字数 = 半角スペース・全角スペース・タブをすべて除去してカウント
5. 改行もスペースも除いた文字数 = 両方を除去してカウント

> **重要**: \r\n は 2文字ではなく改行1つ（2文字分）として扱う。カウント時は文字単位で数える（バイト数ではない）。

## 動作例

入力テキスト：
```
こんにちは　世界
Hello World
```

出力：
```
📊 文字数カウント結果

| パターン               | 文字数 |
|----------------------|--------|
| 改行あり・スペースあり  |     21 |
| 改行あり・スペースなし  |     18 |
| 改行なし・スペースあり  |     20 |
| 改行なし・スペースなし  |     17 |

📝 内訳
- 改行文字数：1 文字
- スペース文字数（半角/全角/タブ）：3 文字
```

## ガイドライン

- テキストが渡されていない場合は「カウントするテキストを貼り付けてください」と促す
- コードブロック内のテキストも含めてカウントする（特に指示がない限り）
- 絵文字・記号・数字はすべて1文字として数える（サロゲートペアも1文字扱い）
- ユーザーが「スペースを半角のみ対象に」などと条件を絞った場合はそれに従い、変更点を明示する
