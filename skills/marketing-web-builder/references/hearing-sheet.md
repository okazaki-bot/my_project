# ヒアリング深掘り質問集（2段目）

必須7問（SKILL.md）の回答を見て、**弱い箇所だけ**追加で聞く。全部聞くと回答されない。
1回の追加質問は **5問まで**。

---

## 判定：どこを深掘りするか

| 必須7問の症状 | 深掘りするブロック |
|---|---|
| Q3の答えが属性だけ（「30〜40代のファミリー層」） | → A. ターゲット深掘り |
| Q5が抽象語（「丁寧な対応」「地域密着」「アットホーム」） | → B. 強み深掘り |
| Q6が「特にない」「分からない」 | → C. 競合深掘り（＋自分で競合サイトを調べる） |
| Q2に複数のCVが並んでいて優先が不明 | → D. CV・オファー深掘り |
| Q1に価格の情報がない | → E. 価格・提供プロセス深掘り |
| Q7がほぼ空欄 | → F. 素材の代替深掘り |
| 全部そこそこ埋まっている | → G. 成約の再現性（最も効く。余裕があれば必ず聞く） |

---

## A. ターゲット深掘り

1. 直近で成約した3件のお客様は、それぞれどんな方でしたか？（年代・家族構成・住まいの状況・きっかけ）
2. その方は、最初にどんな言葉で問い合わせてきましたか？（できればメールや電話の第一声のまま）
3. 逆に、**受注したくない**お客様はどんな方ですか？（過去に苦労した案件の共通点）
4. お客様が動き出すきっかけになった出来事は何でしたか？（家族の変化・近所の建替え・値上げのニュースなど）
5. 相談時、ご本人以外に誰が同席しますか？／誰の了承が必要ですか？

**狙い**：ペルソナの「口にしない悩み」と決裁構造を掘る。3の「来なくていい客」は、ポジショニングの引き算の材料になる。

## B. 強み深掘り

1. 成約したお客様が「決め手」として口にした言葉を、**そのまま**教えてください（3件分）
2. 他社に依頼した見込み客が、断ってきた理由は何でしたか？
3. 御社が「ここは他社より手間をかけている」と言える作業は具体的に何ですか？（工程・回数・時間）
4. 数字で言えることはありますか？（創業年、施工棟数、スタッフ数、資格数、対応エリアの範囲、平均◯◯）
5. 「うちはこれはやりません」と言えることはありますか？

**狙い**：抽象語を事実に変換する。1と5がいちばん強い。1が出てくれば、それがほぼキャッチコピーになる。

## C. 競合深掘り

1. お客様から「◯◯さんとも話しています」と言われる会社名を教えてください（社名だけでも）
2. その会社と比べられたとき、どこで負けますか？どこで勝ちますか？
3. 価格帯は、その会社と比べて高いですか安いですか？（同等なら「同等」で）
4. その会社にはない、御社だけができることはありますか？
5. 業界の常識で、御社が「あれはおかしい」と思っていることはありますか？

**狙い**：空いている席を探す。5は逆張り訴求の材料になる。競合社名が出たら、こちらでサイトを見に行ってポジショニング表を埋める。

## D. CV・オファー深掘り

1. 問い合わせから成約までの流れを、ステップで教えてください（何回会うか、何日かかるか）
2. 初回の接点で、お客様は何をされるのが不安だと思いますか？
3. 初回相談は無料ですか？所要時間は？その場で何を渡せますか？
4. 「まだ検討段階です」という方の比率はどれくらいですか？
5. 電話・メール・LINEのうち、いちばん成約しやすいのはどれですか？受付時間は？

**狙い**：ハードルとリスクリバーサルを設計する。4の数字は「まだ決まってなくても大丈夫」の根拠になるので必ず聞く。

## E. 価格・提供プロセス深掘り

1. 総額の幅を教えてください（いちばん安い実例といちばん高い実例）
2. その総額に含まれるもの／含まれないものは何ですか？（諸費用・外構・地盤・家具など）
3. 予算が合わなかったお客様には、どう対応していますか？
4. 見積を出すまでに必要な情報と、かかる日数は？
5. 支払いのタイミングと方法（分割・つなぎ融資など）を教えてください

**狙い**：価格を隠さない設計にする。2は「予算オーバー」の反論処理に直結する。

## F. 素材の代替深掘り

1. 過去のパンフ・チラシ・名刺・提案書はありますか？（写真とコピーが取れることが多い）
2. Instagram・Facebook・LINE公式に写真は上がっていますか？（URLを）
3. 現場写真はスマホで撮ったものでも構いません。ありますか？
4. お客様アンケートや、引渡し時にもらった手紙などは残っていますか？
5. これから撮影する余地はありますか？（あるなら撮影リストを作ります）

**狙い**：「素材がない」は多くの場合「整理されていない」。既存媒体から掘り起こす。

## G. 成約の再現性（最も効く質問。可能なら必ず聞く）

1. **いちばん理想に近かったお客様1組**を思い出してください。その方は、最初にどんな状態で来て、
   何を見て・何を聞いて、最後に何と言って決めましたか？（できるだけ長く）
2. その体験を、他のお客様にも再現するとしたら、**最初に何を伝えるべき**だと思いますか？
3. 逆に、いちばん惜しかった失注案件は、どこでつまずいたと思いますか？

**狙い**：1の答えの中に、ページの構成そのものが入っている。「何を見て」の順番が、そのまま読者の質問の順番になる。

---

## 回答が返らないときの扱い

- Q1・Q2・Q3のいずれかが空 → **設計に進まない**。この3つだけでも回答を待つ
- それ以外が空 → 仮説を立てて `【仮説：…／要確認】` と明示して進める。仮説は本文に混ぜず、
  該当箇所に注記として残す
- 「分かりません」が続く場合 → 質問の仕方を変える。抽象を聞くのではなく、**具体的な直近の1件**を聞く
  （「強みは何ですか」→「先月成約したお客様は、なぜ御社を選んだと言っていましたか」）

## ヒアリングの記録

`00-hearing.md` に、質問と回答をそのまま残す。要約しない。
クライアントの生の言い回しは、そのままコピーに使えることが多いので、言葉を整えずに保存する。
