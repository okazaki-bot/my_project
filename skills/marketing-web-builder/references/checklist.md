# 公開前チェックリスト

**このリストは提示するだけ。Claudeが採点したり、独断で直したりしない。**
案件の内容に合わせて具体化して出す（「CTAが確信のピークにあるか」ではなく
「価格の内訳を見せた直後（セクション4の後）にCTAがあるか」のように、その案件の実物を指して書く）。

---

## 1. マーケティング（訴求が通っているか）

- [ ] ファーストビューだけを3秒見て「何のページ・自分向けか・次に何をするか」が分かるか
- [ ] 想定した流入経路（検索語／広告／QR）から来た人にとって、第一声が合っているか
- [ ] 「自分向けか」の判断材料（対応エリア・価格帯・対象条件）が上から3スクロール以内にあるか
- [ ] すべての主張の隣に証拠（数字・写真・第三者の声）があるか
- [ ] 競合サイトにそのままコピペできる文章が残っていないか
- [ ] 反論リストの8個が、それぞれページ内のどこかで処理されているか
- [ ] 価格の情報（幅でも範囲でも）が出ているか。隠していないか
- [ ] CTAが「確信のピーク」の直後に置かれているか
- [ ] CTAの直前に、ハードルの低さ・リスクリバーサル・次に起きることが書かれているか
- [ ] 会社の想い・沿革が上部を占拠していないか

## 2. コピー

- [ ] **h2だけを上から通読して、話が通じるか**（最重要）
- [ ] 抽象語（安心・高品質・豊富な実績・丁寧な対応・こだわり・ワンストップ）が具体なしで残っていないか
- [ ] キャッチコピーが30字前後で、スマホ2行以内に収まっているか
- [ ] 数字に時点・条件・概算注記があるか
- [ ] トーン（A/B/C）が1ページ内で統一されているか
- [ ] 一文が40字前後か。60字超の文が残っていないか
- [ ] 同じ語尾が3回以上続いていないか
- [ ] ボタン文言が「送信」「お問い合わせ」ではなく、行動の結果になっているか
- [ ] マイクロコピー（電話番号横・フォーム上・送信後の案内）が入っているか
- [ ] 誤字脱字・社名／人名／地名の表記ゆれがないか
- [ ] 使わない表現（絶対・完全・No.1・日本一・必ず・他社批判）が混じっていないか

## 3. 事実確認（ユーザー／クライアント側で要確認）

- [ ] `【要確認：…】` が1つも残っていないか（残っているなら、それが未確定であることを合意済みか）
- [ ] 実績数値（棟数・年数・割合）の出典と時点が正しいか
- [ ] お客様の声は、実在するものか。掲載許可を取得済みか。氏名の匿名化が済んでいるか
- [ ] 価格・仕様・キャンペーン期限が最新か
- [ ] 免許番号・資格・加盟団体の記載が正しいか
- [ ] 写真に写り込んだ他社ロゴ・第三者の顔・車のナンバーがないか
- [ ] 掲載している写真の使用権があるか（自社撮影か、許諾済みか）

※ 広告表現の適法性（景表法・不動産の表示に関する公正競争規約など）の判断は、このスキルの範囲外。
必要なら別途、専門家または別工程で確認してください。

## 4. 実装・表示

- [ ] スマホ実機（または375px幅）で横スクロールが出ないか
- [ ] 本文が16px以上、行間1.8以上か
- [ ] タップ領域が44×44px以上あるか。ボタンが隣接して誤タップしないか
- [ ] 固定フッターCTAが本文の末尾を隠していないか
- [ ] 画像に width / height が入っていて、読み込み時に文字が飛ばないか
- [ ] alt が適切か（装飾は空、内容を伝えるものは説明あり）
- [ ] 文字色と背景のコントラストが十分か（薄いグレー文字になっていないか）
- [ ] ブラウザのコンソールにエラーが出ていないか
- [ ] ページ内リンク（CTA → フォーム）が正しく飛ぶか
- [ ] 電話番号が `tel:` リンクになっていて、スマホでタップできるか
- [ ] `<title>` と `meta description` が入っていて、内容が合っているか
- [ ] 画像が重すぎないか（1点あたり300KB以内を目安に）

## 5. フォーム

- [ ] 送信先（action / プラグイン設定 / 通知メール）が設定済みか
- [ ] **実際にテスト送信して、通知メールが届いたか**
- [ ] 入力項目が最小限か。削れる項目はないか
- [ ] 必須／任意がラベルに明示されているか
- [ ] autocomplete / inputmode が入っていて、スマホで入力しやすいか
- [ ] 送信後の完了画面（またはメッセージ）が用意されているか
- [ ] 個人情報の取り扱いについての一文があるか
- [ ] 迷惑メールフォルダに入らないか確認したか

## 6. 素材

- [ ] プレースホルダが全部、実素材に差し替わっているか
- [ ] 差し替え時に比率が崩れていないか（縦横が入れ替わっていないか）
- [ ] ビフォーアフター写真の撮影アングルが揃っているか
- [ ] ロゴが荒れていないか（ラスタ画像を拡大していないか）
- [ ] ファビコンが設定されているか

## 7. 公開

- [ ] 公開先（GitHub Pages / Vercel / XServer / WordPress）をユーザーに確認したか
- [ ] WordPressの場合、既存ページを上書きしていないか（新規固定ページか、バックアップを取ったか）
- [ ] 貼り付け用テキストがUTF-8（BOMなし）で、文字化けしていないか
- [ ] 公開URLを実機で開いて確認したか
