# 相続シミュレーター 計算ロジック仕様書

- 対象バージョン: v2.1（2026-07-05）
- 実装ファイル: `js/taxtables.js`（数表）／`js/engine.js`（計算エンジン）／`js/asset-strategy.js`（対策シミュレーション）
- 本書は、アプリに組み込まれているすべての計算式・数値・根拠法令・実装上の前提（簡略化した点）を記録するものです。

> **免責**: 本アプリの計算はすべて概算です。実際の申告・対策の実行にあたっては税理士に確認してください。

## 1. 法定相続人と法定相続分

**根拠**: 民法887条（子・代襲）、889条（直系尊属・兄弟姉妹）、890条（配偶者）、900条（法定相続分）、901条（代襲相続人の相続分）

| 構成 | 配偶者 | 血族相続人 |
|---|---|---|
| 配偶者＋子（第1順位） | 1/2 | 1/2 を子の数で均分 |
| 配偶者＋直系尊属（第2順位） | 2/3 | 1/3 を人数で均分 |
| 配偶者＋兄弟姉妹（第3順位） | 3/4 | 1/4 を人数で均分 |
| 配偶者のみ | 全部 | — |

- **順位の判定**: 子（代襲の孫を含む）がいれば第1順位のみ。いなければ直系尊属、それもいなければ兄弟姉妹（代襲の甥姪を含む）。
- **代襲相続**: 代襲者（孫・甥姪）は「代襲元」ごとにグループ化し、被代襲者1人分の相続分をグループ内で均分（実装: `legalHeirs()` の `daishuFrom` グループ処理）。
- **実装上の簡略化**: 半血兄弟姉妹（父母の一方のみ同じ・相続分1/2）、養子の数の制限（相続税法15条2項: 実子ありは1人・なしは2人まで）、廃除・欠格の個別判定は未実装。該当がある場合は手動調整が必要。

## 2. 相続税の計算フロー

**根拠**: 相続税法11条〜20条／実装: `calcTax()`

### 2.1 各人の課税価格

```
課税価格 = 取得財産の評価額合計
         + みなし相続財産（非課税枠控除後）
         − 債務・葬式費用の負担額
（1,000円未満切捨て）
```

### 2.2 みなし相続財産の非課税枠（相続税法12条1項5号・6号）

```
生命保険金の非課税限度額 = 500万円 × 法定相続人の数
死亡退職金の非課税限度額 = 500万円 × 法定相続人の数
```

- 非課税枠は**法定相続人が受け取った分**にのみ適用（相続放棄者・受遺者は対象外）。
- 複数人が受け取る場合は受取額に応じて按分控除。
- 法定相続人の数は養子制限前の入力人数をそのまま使用（簡略化）。

### 2.3 基礎控除（相続税法15条）

```
基礎控除額 = 3,000万円 + 600万円 × 法定相続人の数
課税遺産総額 = 課税価格の合計 − 基礎控除額（マイナスなら0）
```

### 2.4 相続税の総額（相続税法16条）

課税遺産総額を**法定相続分どおりに取得したものと仮定**して各人分を計算（1,000円未満切捨て）し、速算表を適用して合算する。

**相続税の速算表**（`TAX_TABLE`）

| 法定相続分に応ずる取得金額 | 税率 | 控除額 |
|---|---|---|
| 1,000万円以下 | 10% | — |
| 3,000万円以下 | 15% | 50万円 |
| 5,000万円以下 | 20% | 200万円 |
| 1億円以下 | 30% | 700万円 |
| 2億円以下 | 40% | 1,700万円 |
| 3億円以下 | 45% | 2,700万円 |
| 6億円以下 | 50% | 4,200万円 |
| 6億円超 | 55% | 7,200万円 |

相続税の総額は100円未満切捨て。

### 2.5 各人の算出税額（相続税法17条）

```
各人の算出税額 = 相続税の総額 × （各人の課税価格 ÷ 課税価格の合計）
```

### 2.6 2割加算（相続税法18条）

**対象外**（加算なし）: 配偶者、子、父母、代襲相続人となった孫
**対象**（税額×1.2）: 兄弟姉妹、甥姪、受遺者（その他）、祖父母

- 実装: `isKasan()`。孫養子（代襲でない孫が養子として相続）は加算対象だが、続柄選択に「孫養子」がないため「その他（受遺者等）」で入力すると正しく加算される。

### 2.7 配偶者の税額軽減（相続税法19条の2）

```
軽減額 = 相続税の総額 × min(配偶者の課税価格, 軽減限度額) ÷ 課税価格の合計
軽減限度額 = max(1億6,000万円, 課税価格の合計 × 配偶者の法定相続分)
```

- 実装上、軽減額は配偶者の算出税額（2割加算後）を上限とする。
- 申告期限までの分割確定が要件だが、アプリでは常に適用（簡略化）。

### 2.8 相次相続控除（相続税法20条）

前回相続（今回の被相続人が財産を取得した相続）から10年以内の場合:

```
各人の控除額 = A × C/(B−A)【100/100を超える場合は100/100】 × D/C × (10−E)/10

A = 前回相続で被相続人が納めた相続税額
B = 前回相続で被相続人が取得した財産価額
C = 今回の課税価格の合計
D = その相続人の課税価格
E = 前回相続から今回までの経過年数（1年未満切捨て）
```

- 対象は法定相続人のみ（相続放棄者等は対象外）。

### 2.9 各人の納税額

```
納税額 = 算出税額 + 2割加算 − 配偶者の税額軽減 − 相次相続控除
（マイナスなら0、100円未満切捨て）
```

**未実装の税額控除**: 贈与税額控除（暦年課税分・精算課税分）、未成年者控除（10万円×18歳までの年数）、障害者控除（10万円/20万円×85歳までの年数）、外国税額控除。

## 3. 遺留分（民法1042条）

```
総体的遺留分 = 1/2（直系尊属のみが相続人の場合は 1/3）
各人の遺留分 = 総体的遺留分 × その者の法定相続分
兄弟姉妹・甥姪には遺留分なし
```

- 遺留分算定基礎は本来「相続財産＋一定の生前贈与−債務」だが、アプリでは課税価格合計で代用（簡略化）。

## 4. 不動産評価

### 4.1 路線価方式（財産評価基本通達11〜20-7）

実装: `valuateRosenka()`。計算順序は「土地及び土地の上に存する権利の評価明細書」に準拠。

```
① 1㎡単価 = 正面路線価 × 奥行価格補正率（通達15・付表1）
② ＋ 側方路線価 × 奥行価格補正率(側方から見た奥行=間口距離で近似) × 側方路線影響加算率（通達16・付表2）
③ ＋ 裏面路線価 × 奥行価格補正率 × 二方路線影響加算率（通達17・付表3）
④ × 補正率（下記いずれか）
   ・整形地: 間口狭小補正率（付表6） × 奥行長大補正率（付表7）
   ・不整形地（通達20）: min( 不整形地補正率(付表4・5) × 間口狭小補正率,
                              奥行長大補正率 × 間口狭小補正率 )
     …小数点2位未満切捨て・下限0.60
⑤ × がけ地補正率（通達20-5・付表8）
   土砂災害特別警戒区域（通達20-6・付表9）併用時は 特別警戒補正率×がけ地補正率（下限0.50）
⑥ × 地積 = 自用地価額
⑦ 無道路地（通達20-3）: 通路開設費用（正面路線価×通路地積）を控除、控除は価額の40%が上限
⑧ セットバック（通達24-6）: 価額 × (該当地積/総地積) × 0.7 を控除
⑨ 私道（通達24）: 行き止まり私道は×0.3、通り抜け私道は評価しない（0円）
⑩ 宅地造成費の控除（通達40ほか・市街地農地等）: Σ(数量 × 単価)
⑪ 権利調整（→4.4）
```

**数表の出典**: 付表1〜9の全数値は国税庁「財産評価基本通達 付表」
https://www.nta.go.jp/law/tsutatsu/kihon/sisan/hyoka_new/02/07.htm
から取得し `js/taxtables.js` に収録（2026-07-05取得）。

- 付表1 奥行価格補正率表（地区区分7種 × 奥行29区分）
- 付表2 側方路線影響加算率表（角地/準角地）
- 付表3 二方路線影響加算率表
- 付表4 地積区分表（A/B/C判定。ビル街・大工場は不整形地補正の適用なし）
- 付表5 不整形地補正率表（かげ地割合10〜65%・5%刻み）
- 付表6 間口狭小補正率表
- 付表7 奥行長大補正率表（奥行÷間口 2以上で適用）
- 付表8 がけ地補正率表（南・東・西・北）
- 付表9 特別警戒区域補正率表（0.10→0.90／0.40→0.80／0.70→0.70）

**かげ地割合**（不整形地・通達20）:

```
かげ地割合 = (想定整形地の地積 − 評価対象地の地積) ÷ 想定整形地の地積
```

**借地権割合の記号**（路線価図）: A=90% B=80% C=70% D=60% E=50% F=40% G=30%

**実装上の簡略化**:
- 側方路線の奥行補正は「側方路線から見た奥行距離＝正面の間口距離」で近似（厳密には側方路線からの実際の奥行）。
- 正面路線の判定（路線価×奥行補正が最大の路線が正面）はユーザー入力に委ねる。
- 屈折路・帯状地・地積規模の大きな宅地（通達20-2、三大都市圏500㎡/その他1,000㎡以上の規模格差補正）は未実装。

### 4.2 倍率方式（通達21-2）

```
評価額 = 固定資産税評価額 × 評価倍率
```

倍率は国税庁「評価倍率表」（rosenka.nta.go.jp）で確認して入力。

### 4.3 建物（通達89・93）

```
自用家屋 = 固定資産税評価額 × 1.0
貸家     = 固定資産税評価額 × (1 − 借家権割合30% × 賃貸割合)
```

借家権割合は全国一律30%（`SHAKKA = 0.30`）。

### 4.4 土地の権利調整（通達25・26・27）

```
貸宅地     = 自用地価額 × (1 − 借地権割合)
貸家建付地 = 自用地価額 × (1 − 借地権割合 × 借家権割合30% × 賃貸割合)
借地権     = 自用地価額 × 借地権割合
```

### 4.5 区分所有マンション（令和5年9月28日付 法令解釈通達「居住用の区分所有財産の評価について」・令和6年1月1日以後適用）

実装: `kubunShoyuHosei()`

```
評価乖離率 = A + B + C + D + 3.220
  A = 築年数 × ▲0.033           （築年数は1年未満切上げ）
  B = 総階数指数 × 0.239          （総階数指数 = min(1, 総階数÷33)、小数点以下第4位切捨て。Bも第4位切捨て）
  C = 所在階 × 0.018             （地階は0階として計算）
  D = 敷地持分狭小度 × ▲1.195     （狭小度 = 敷地利用権面積÷専有面積、第4位切上げ。Dも第4位切上げ）

評価水準 = 1 ÷ 評価乖離率

区分所有補正率:
  評価水準 < 0.6  → 評価乖離率 × 0.6
  0.6 ≦ 水準 ≦ 1 → 補正なし（1.0）
  水準 > 1       → 評価乖離率
```

```
敷地利用権 = 敷地全体の自用地評価額 × 敷地権割合 × 区分所有補正率
区分所有権（建物） = 専有部分の固定資産税評価額 × 区分所有補正率
賃貸中: 敷地 × (1−借地権割合×30%)、建物 × (1−30%)
```

**検証**: 築15年・総階数11階・所在階3階・専有59.69㎡・敷地利用権12.24㎡のケースで
評価乖離率2.611・補正率1.567 を確認（国税庁の計算例と一致）。

### 4.6 時価の目安（活用シミュレーション）

```
時価目安 = 自用地評価額 ÷ 0.8
```

根拠: 路線価は地価公示価格水準の約80%を目途に設定されている（国税庁公表の評価方針）。あくまで初期値であり、実際の相場（不動産情報ライブラリ・SUUMO等）で上書きする前提。

## 5. 小規模宅地等の特例（租税特別措置法69条の4）

| 区分 | 減額割合 | 限度面積 |
|---|---|---|
| 特定居住用宅地等 | 80% | 330㎡ |
| 特定事業用宅地等 | 80% | 400㎡ |
| 貸付事業用宅地等 | 50% | 200㎡ |

```
減額額 = 対象宅地の評価額 × 減額割合 × (適用面積 ÷ 地積)
```

**併用の限度面積**:
- 貸付事業用を使わない場合: 居住用330㎡＋事業用400㎡（最大730㎡まで完全併用可）
- 貸付事業用を使う場合:
  `事業用適用面積 × 200/400 ＋ 居住用適用面積 × 200/330 ＋ 貸付用適用面積 ≦ 200㎡`

**最適化アルゴリズム**（`optimizeTokurei()`）:
1. 案1（貸付なし）: 居住用・事業用それぞれ「1㎡あたり減額額」の大きい土地から限度面積まで充当
2. 案2（貸付あり）: 上記の限度面積式は単一の線形制約なので、「1㎡あたり減額額 ÷ 制約消費係数」の効率順に詰める**分数ナップサック**で厳密解が得られる
3. 減額合計が大きい方を採用

**注意（アプリ内にも表示）**: 取得者要件（配偶者・同居親族・家なき子等）、貸付事業用の3年縛り（相続開始前3年以内に貸付開始した宅地は原則対象外、措置法69条の4③）は判定していない。

## 6. 最適分割の探索（`runDivisionSweep()`）

- 配偶者の取得割合 s を 0〜100%（1%刻み・101点）でスイープ。配偶者以外は法定相続分の比率で残りを按分。
- 各点で一次相続税（本仕様書§2）を計算。
- **二次相続の概算**:

```
二次相続の課税財産 = 配偶者の固有財産 + 一次で取得した課税価格 − 一次での納税額
二次相続税 = 通常の相続税計算（相続人 = 一次の配偶者以外の法定相続人、均等取得と仮定、配偶者控除なし）
```

- 合計（一次＋二次）最小の s を「おすすめ」として提示。
- **前提・限界**: 配偶者の生活費等による財産減少、二次までの財産評価の変動、死亡保険金（受取人固定のため s に依存しない）、小規模宅地特例の二次での適用は考慮しない。

## 7. 不動産活用シミュレーション（`strategyPlans()`）

比較の前提: 相続税額はすべて「法定相続分で分割した場合」で統一して比較。

### 7.1 売却プラン

```
仲介手数料 = (売却価格 × 3% + 6万円) × 1.1（消費税10%）
           …宅建業法46条・報酬告示の上限（400万円超の物件）

譲渡所得 = 売却価格 − 取得費 − 仲介手数料
  取得費が不明な場合は概算取得費 = 売却価格 × 5%（措置法31条の4）

譲渡所得税 = 譲渡所得 × 税率
  長期（所有5年超）: 20.315%（所得税15% + 復興特別所得税0.315% + 住民税5%）
  短期（5年以下）  : 39.63% （所得税30% + 復興特別所得税0.63% + 住民税9%）

手取り額 = 売却価格 − 仲介手数料 − 譲渡所得税
```

相続税への影響: 土地（路線価評価≒時価の8割）が現金（時価100%）に変わるため、課税価格は通常増加する。

**未考慮**: 居住用財産の3,000万円特別控除（措置法35条）、取得費加算の特例、印紙税・登記費用等。

### 7.2 賃貸経営プラン（アパート／戸建賃貸・全額借入を仮定）

**相続税評価の変化**:
```
土地: 自用地 → 貸家建付地 = ×(1 − 借地権割合 × 30% × 賃貸割合100%)
建物: 建築費 × 60%（固定資産税評価の目安） × 70%（貸家） ≒ 建築費の42%で評価
借入金: 全額を債務控除
小規模宅地: 特定居住用 → 貸付事業用（50%/200㎡）に自動変更
```

**収支**:
```
年間返済額（元利均等） = 借入額 × i ÷ (1 − (1+i)^−n) × 12
  i = 年利÷12、n = 返済月数
年間手残り = 年間家賃収入 × (1 − 経費率) − 年間返済額
表面利回り = 年間家賃収入 ÷ 建築費
```

**初期値（すべて画面で変更可能）**:

| 項目 | 初期値 | 備考 |
|---|---|---|
| アパート延床 | 地積×容積率120%相当 | 目安 |
| アパート建築費 | 延床坪数 × 90万円/坪 | 木造の相場観 |
| 戸建賃貸建築費 | 最大35坪 × 85万円/坪 | |
| 想定家賃 | 表面利回り アパート7%／戸建6.5%から逆算 | SUUMO相場で上書き推奨 |
| 建物の固定資産税評価 | 建築費 × 60% | 一般的な水準 |
| 借入金利 | 2.0% | |
| 借入期間 | 30年 | |
| 運営経費率 | 20% | 管理費・修繕・固都税等 |
