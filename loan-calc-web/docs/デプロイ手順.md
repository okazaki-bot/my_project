# デプロイ手順（XServer / life-step.jp）

`node build.mjs` で生成される **`dist/index.html`** が、CSS・JavaScriptをすべて内包した自己完結ファイルです。
これ1枚で動作します（外部ライブラリ・サーバー処理なし）。

## 方法A：XServerに直置き（推奨・独立URL）

FTP（FileZilla等）またはXServerのファイルマネージャで、`dist/` の中身をアップロードします。

1. 公開ディレクトリ（例）`/life-step.jp/public_html/` の下に `loan/` フォルダを作成
2. `dist/index.html` を `loan/` にアップロード
   - （念のため `dist/js/`・`dist/css/` も一緒に上げておくと、将来モジュール版に切り替えても動きます。単体運用なら index.html だけでOK）
3. ブラウザで `https://life-step.jp/loan/` を開いて表示確認

→ 公開URL：**https://life-step.jp/loan/**

## 方法B：WordPress固定ページに埋め込む（サイトのメニューに載せたい場合）

方法Aで `loan/` に置いたうえで、固定ページにiframeで埋め込むのが最も安全です
（テーマ更新やプラグインの影響を受けにくく、CUBIC LPと同じ運用）。

固定ページを「カスタムHTML」ブロックで作成し、以下を貼り付け：

```html
<iframe src="https://life-step.jp/loan/" style="width:100%;height:1800px;border:0;" loading="lazy" title="住宅ローンシミュレーター"></iframe>
```

- 高さ `height` はページ内容に合わせて調整（1600〜2000px程度）
- スマホでも横スクロールで償還表・比較表を確認できます

## 更新方法

1. `js/`・`css/`・`index.html` を編集
2. `node build.mjs` を再実行 → `dist/index.html` が更新される
3. `dist/index.html` を同じ場所にアップロードで上書き

## 注意

- 本ツールはブラウザ内だけで計算し、入力値をどこにも送信しません（サーバー保存なし）
- 概算値であり、実際の金融機関の計算とは端数処理等で差が出る旨のフッター注記あり
