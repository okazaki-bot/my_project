# 住宅ローン シミュレーター（loan-calc-web）

iPhoneアプリ「ローン計算 iLoan Calc（アイローンカルク）」と同等の機能をWebで再現した住宅ローン計算ツール。
サーバー不要の静的サイト（HTML + CSS + 素のJavaScript）。

## 機能

- 返済方法: 元利均等 / 元金均等
- 段階金利（○年目から金利変更、複数段階可）
- ボーナス併用払い（ボーナス月2つを指定、半年賦で計算）
- 繰上げ返済: 期間短縮型 / 返済額軽減型を何回でも設定可
- 2プラン比較（A/B）: 毎月返済額・総返済額・利息・完済時期の比較表＋差額表示
- 年次比較表（⑤・「比較する」ON時に表示）: 協会Excel「住宅ローン比較表」と同形式で、A/Bを年ごとに横並び（金利・返済額・利息・元金・元金残高）＋右端に月額差(B−A)、繰上げ返済の年にタグ表示
- ローン残高推移グラフ（Canvas描画・外部ライブラリなし）
- 償還表（年ごと集計 / 毎月全回数）・CSVダウンロード
- 借入可能額の試算（年収×返済負担率 or 希望月返済額から）

## 構成

- `index.html` — 画面
- `css/style.css` — スタイル
- `js/calc.js` — 計算エンジン（純粋関数・DOM非依存。Nodeで単体テスト可能）
- `js/app.js` — UI・描画

## 起動方法

```
npx serve loan-calc-web -p 8779
```

または `.claude/launch.json` の `loan-calc-web` 設定（ポート8779）。

## 検証済みの数値

- 3,000万円・年1.5%・35年・元利均等 → 毎月91,855円（市販ツールと一致）
- 5年後に300万円繰上げ（期間短縮型）→ 期間371回に短縮・利息約156万円軽減
- 借入可能額: 年収600万・負担率35%・審査金利3.5%・35年 → 4,234万円

## 計算上の注意（仕様）

- 利息は毎回「残高×月利」の円未満切捨て、返済額は円未満四捨五入
- ボーナス分は半年賦（年利÷2）の独立ローンとして計算（一般的な近似）
- 繰上げ返済は毎月分の残高にのみ充当（ボーナス分には充当しない）
- 繰上げ手数料・保証料返戻・団信は未考慮
