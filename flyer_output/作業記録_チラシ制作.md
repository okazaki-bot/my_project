## 7. 技術的な再現手順（重要）

### 7-1. HTML → A4 PDF 変換
```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="出力.pdf" --no-margins "file:///絶対パス/入力.html"
```
HTML側の印刷指定：
```css
@media print{
  html,body{background:#fff;}
  .page{margin:0;box-shadow:none;width:210mm;height:297mm;}
  @page{size:A4;margin:0;}
}
```

### 7-2. A4 1ページに収める「計測ループ」（最重要ノウハウ）
`.page` は `min-height:297mm; overflow:hidden;` のため、**溢れても気づかず下が切れる**。
必ず下記でコンテンツの自然高さを測ってから調整する。**A4縦 = 1123px（297mm @96dpi）／横 = 794px**。

```bash
# クリップ・最小高さ・margin-top:auto を外した計測用HTMLを作る
perl -0pe 's/overflow:hidden;\n    box-shadow:0 4px 24px rgba\(0,0,0,.25\);/overflow:visible;/; \
           s/min-height:297mm;/min-height:0;/; s/margin-top:auto;//; s/margin:10px auto;/margin:0 auto;/' \
  入力.html > /tmp/m.html

"$CHROME" --headless --disable-gpu --hide-scrollbars --window-size=794,2700 \
  --screenshot="/tmp/m.png" "file:///tmp/m.html"

# 下から走査して「白でない最後の行」＝コンテンツ末尾を検出
python3 -c "
from PIL import Image
im=Image.open('/tmp/m.png').convert('RGB'); w,h=im.size; px=im.load(); bottom=0
for y in range(h-1,-1,-1):
    for x in range(0,w,4):
        r,g,b=px[x,y]
        if not(r>248 and g>248 and b>248): bottom=y;break
    if bottom: break
print('自然高さ:',bottom,'px | A4=1123 | diff:',bottom-1123,'px')
"
```
- `diff` が **0以下**なら1ページに収まる。プラスなら余白/フォントを詰めて再計測。
- 注意：`body` の背景を白にしないと誤検出する（グレー背景だと全面を「コンテンツ」と誤認）。
- `.cta-band` / `.foot` の `margin-top:auto` が余りを吸収して下端に固定する仕組み。

### 7-3. 画像のBase64埋め込み
```python
import base64
uri = 'data:image/jpeg;base64,' + base64.b64encode(open('koushi.jpg','rb').read()).decode()
html = html.replace('__PHOTO_URI__', uri)
```
HTML側はプレースホルダ（`__PHOTO_URI__` 等）で書いておき、後から差し込むと編集しやすい。

### 7-4. 写真クロップ（sips）
```bash
# 正方形（円形アバター用）
sips "$SRC" --cropToHeightWidth 1620 1620 --cropOffset 600 880 --out /tmp/sq.jpg
sips --resampleWidth 520 /tmp/sq.jpg --out koushi.jpg
# 縦長4:5（プロフィール用）
sips "$SRC" --cropToHeightWidth 2200 1760 --cropOffset 430 780 --out /tmp/p.jpg
sips --resampleWidth 560 /tmp/p.jpg --out koushi_profile.jpg
```
※ `--cropOffset` は **top left** の順。

### 7-5. QRコード生成
```bash
pip3 install qrcode
python3 -c "
import qrcode
from qrcode.constants import ERROR_CORRECT_M
qr=qrcode.QRCode(error_correction=ERROR_CORRECT_M, box_size=20, border=2)
qr.add_data('https://www.lifeplanadvisor.or.jp/seminar/'); qr.make(fit=True)
qr.make_image(fill_color='#16243d', back_color='white').save('qr_seminar.png')
"
```

### 7-6. プレビュー画像の書き出し
```bash
sips -s format jpeg -s formatOptions 88 --resampleWidth 1240 出力.pdf --out プレビュー.jpg
sips -s format png --resampleWidth 1500 出力.pdf --out 確認.png
```
※ HTMLを簡易ビューアで開くとBase64画像が表示されないことがある。**確認はPDFかJPGで行う**。

### 7-7. Amazon 短縮URL → ASIN → 書影
- `amzn.asia/d/xxxx` は curl では追えない。WebFetch でリダイレクト先（`/dp/{ASIN}`）を取得する。
- 商品ページ本体は 500 で拒否されるが、**画像CDNは取得可能**：
  `https://m.media-amazon.com/images/P/{ASIN}.09._SCLZZZZZZZ_.jpg`
