## 1. プロジェクトの背景と目的

- ユーザー（岡崎様）は **2026年11月8日実施の令和8年度行政書士試験** を受験予定。
- 合否を分けるのは **民法・行政法の記述式（問44〜46、各20点×3問＝60点）** という認識。
- 依頼の流れ:
  1. 予備校講師の視点で過去の記述式出題傾向を分析
  2. 出題可能性の高い予想問題集（テーマ的中率で3問カバー率85%超を狙う）を作成 → **120問構成**に決定
  3. 120問を収録した**学習アプリ**を作成（下記仕様）
  4. アプリに**本番モード**を追加

## 2. 出題傾向分析の要点（Web検索で確認済みの事実）

### 直近の記述式出題テーマ
- **令和7年度（2025/11/9実施）**
  - 問44（行政法）: 裁決固有の瑕疵・裁決取消訴訟（原処分主義）
  - 問45（民法）: 761条 日常家事債務と110条趣旨類推（正当の理由）
  - 問46（民法）: 事務管理の継続義務・有益費償還請求
- **令和6年度**
  - 問44（行政法）: 競願関係（電波法）・拒否処分と免許処分の取消訴訟
  - 問45（民法）: 動産売買の先取特権（物上代位・競売）
  - 問46（民法）: 債権者代位権（移転登記請求権の代位行使）

### 分析から導いた出題予測の考え方
- 行政法は**行政事件訴訟法が最頻出**。仮の救済のうち「執行停止」だけが未出題（R5に仮の差止め既出）→ 最本命。
- 国家賠償・損失補償は記述式で長期空白 → 空白地帯を厚くカバー。
- 民法は**改正（債権法・相続法・物権法・親族法）で明文化された論点**と**未出題の王道判例法理**（背信行為論、94条2項類推、時効と登記等）が狙われる。
- 債権者代位権が2回出て詐害行為取消権が未出題 → 民法の最本命。

## 4. アプリ仕様（引き継ぎ用の技術メモ）

### 起動方法
- `app/index.html` をブラウザで直接開くだけで動く（外部依存なし）。
- または静的サーバ: `npx serve 行政書士R8予想問題集/app -p 8748`
- Claude Codeのプレビュー構成 `.claude/launch.json` に **`r8-kijutsu-app`**（ポート8748）を登録済み。

### 学習フロー（2モード）
- **練習モード**: ①出題 → ②模範解答＋採点キーワード解説を先に確認 → ③解答を隠して答案作成 → ④採点・解説
  ※「先に答えを学んでから再現する」というユーザー指定の独自フロー。
- **本番モード**: ①出題 → ②いきなり答案作成 → ③採点・解説（本試験と同じ流れ）
- モードはホームで切替、localStorageに保存、履歴にもモードを記録（練習=緑/本番=赤バッジ）。

### 採点方式
- 各問に採点キーワード3つ（配点合計20点）。答案文字列とキーワードの照合語（`m`配列）の部分一致で**自動採点**。
- 自動判定はチェックボックスで**手動修正可能**（同趣旨の別表現に対応）。
- 全120問の配点合計が20点になることを検証済み。

### 記録・反復（間隔反復）
- localStorage `r8kijutsu_history_v1`: 回答履歴 `{qid, date(ISO), score, ans, hits[], mode}`
- localStorage `r8kijutsu_mode_v1`: "practice" | "exam"
- 復習期日: 直近得点 **16点以上→7日後 / 10〜15点→3日後 / 10点未満→翌日**。未回答は常に復習対象。
- ホーム「今日の復習」は低得点・未回答を先頭にソート。
- 履歴画面: 日別平均点チャート（直近14日）＋直近100件の一覧。
- **注意: データはブラウザのlocalStorage保存。ブラウザを変えると履歴は引き継がれない**（エクスポート機能は未実装＝今後の課題）。

### データ形式（問題を追加・修正する場合）
```js
{id:"GA01", sub:"行政法", rank:"A", theme:"執行停止（行訴法25条）",
 q:"問題文（事例＋40字程度で記述しなさい）",
 model:"模範解答（40字前後）",
 kw:[{t:"採点キーワード名", p:8, m:["照合語1","照合語2"], n:"解説"}, ...], // pの合計=20
 basis:"出題根拠（なぜR8に出るか）",
 expl:"補足解説"}
```
各 `data_*.js` は `window.QUESTION_SETS.push([...])` で登録。IDは GA/GB/GC（行政法）、MA/MB/MC（民法）＋連番。
